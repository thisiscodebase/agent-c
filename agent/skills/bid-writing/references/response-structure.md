# Response structure — per tender question

For every tender question, structure the answer as follows:

1. **Direct, compliance-led answer** in plain English, aligned to the evaluation criteria.
2. **Clear mapping:** Requirement → Our Approach → Evidence (Std BD Pack citation) → Measurable Benefit.
3. **Outputs and outcomes** with quantified KPIs and targets (only where evidenced; never invent).
4. **Delivery methodology and governance**, including an explicit end-to-end user journey (see `emcca-feedback.md`).
5. **Accessibility and inclusion approach** (digitally excluded, underserved groups, time-poor / geographically dispersed).
6. **Risk management and mitigations.**
7. **Value for money and additionality.**

Use clear headings, short paragraphs, numbered commitments, and tables where they aid the assessor.
